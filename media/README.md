# media/ · 仓库素材目录

把视频 / 音频放进这个目录，并在 `manifest.json` 的 `items` 里登记，网站就能在**任意设备**打开同一网址直接建课播放，无需逐台重新上传文件本体。

## 原理
- 文件随网站一起托管在 GitHub Pages，`media/xxx.mp4` 是同域直链，任何设备都能加载。
- 前端在「我的素材库」自动读取 `media/manifest.json`，列出仓库里的素材，点「用这个建课」即可。
- 这些素材会进入「我的素材库」的课程数据；课程本身仍可随**同步链接 / 自动云同步**跨设备迁移（视频本体不进同步链接，靠仓库直链复用）。

## 怎么加一个新视频

1. 把文件复制到本目录，例如 `media/sample.mp4`。
2. 把字幕（srt/vtt/lrc）也放进本目录，例如 `media/sample.vtt`。
3. 编辑 `manifest.json`，在 `items` 数组里加一条：

```json
{
  "title": "我的演示视频",
  "file": "sample.mp4",
  "level": "B1",
  "subs": "sample.vtt"
}
```

4. 提交并推送到 GitHub，等 Pages 重新构建（约 1 分钟）后刷新网站。

## 限制 / 注意
- **体积**：GitHub 单文件软上限约 100MB、仓库建议不超过 1GB，单个视频建议压到 100MB 内（H.264/AAC 的 mp4 兼容性最好）。超大的视频请改用外链或网盘直链。
- **隐私**：本仓库是**公开**的，`media/` 下的文件对所有能访问网站的人可见。请勿放私密或侵权内容，仅供个人学习使用，版权归原作者。
- **CORS**：同源 `media/` 路径无需跨域；若用第三方直链，需对方服务器允许该域名加载（失败时可下载后改用上传本地文件）。
- 仅登记 `file` 但文件不存在时，建课会显示「本地媒体已不在」，请确认文件名与 `manifest.json` 完全一致（区分大小写）。
